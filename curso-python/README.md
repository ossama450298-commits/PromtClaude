# 🐍 Curso de Python desde cero

Un curso práctico, en español, para aprender a programar en Python **sin conocimientos previos**.
Cada módulo tiene una explicación, ejemplos que puedes copiar y ejecutar, y ejercicios con su solución.

---

## Cómo usar este curso

1. **Sigue el orden.** Cada módulo usa lo que aprendiste en los anteriores.
2. **Escribe el código tú mismo.** No lo copies y pegues: teclearlo es parte del aprendizaje.
3. **Haz los ejercicios antes de mirar la solución.** Equivocarse es normal y es cómo se aprende.
4. **Ritmo recomendado:** 1 módulo cada 2–3 días, dedicando 45–60 minutos al día.
   En unas **5–6 semanas** habrás terminado el curso y el proyecto final.

## ¿Y después?

Cuando termines tendrás una base sólida. Caminos para seguir:

- **Desarrollo web:** Flask o Django.
- **Análisis de datos:** pandas, matplotlib, Jupyter.
- **Automatización:** scripts para ordenar archivos, enviar correos, rellenar Excel (`openpyxl`).
- **Práctica diaria:** ejercicios en [exercism.org](https://exercism.org/tracks/python) o [codewars.com](https://www.codewars.com).
- **Documentación oficial (en español):** [docs.python.org/es/3/tutorial](https://docs.python.org/es/3/tutorial/)
